📖 الدرس الأول: الخوارزميات

تعريف الخوارزمية: هي عدد منته من الخطوات المتسلسلة لتحقيق هدف محدد في زمن منته يمكن التعبير عنها باللغة التي نريد.

يمكن أن تكون الخوارزمية:

  1. حسابية: تحتوي على عمليات حسابية مثل جمع أعداد.
  2. غير حسابية: مثل خطوات الاستيقاظ الصباحي والذهاب إلى المدرسة.

خصائص الخوارزمية:

  1. منتهية: عدد خطواتها محدود.
  2. متسلسلة: ذات ترتيب منطقي.
  3. محددة الهدف.
  4. زمن تنفيذها محدد.
  5. قابلة للفهم والتعبير.

مكونات أي خوارزمية:

  • المدخلات (الدخل): المعطيات التي تُجرى عليها العمليات.
  • المعالجة: العمليات التي تُجرى على المدخلات (جمع، طرح، ضرب، قسمة، مقارنة...).
  • المخرجات (الخرج): النتيجة النهائية.

📝 تطبيق: خوارزمية جمع عددين

تحليل المسألة:

  • المدخلات: عددان A و B
  • المعالجة: C = A + B
  • المخرجات: C (مجموع العددين)

خطوات العمل:

1. البداية
2. أدخل قيمة A, B
3. احسب C = A + B
4. اطبع C
5. النهاية

📝 تطبيق: خوارزمية مساحة مستطيل

تحليل المسألة:

  • المدخلات: الطول L والعرض W
  • المعالجة: S = L × W
  • المخرجات: S (المساحة)

خطوات العمل:

1. البداية
2. أدخل الطول L والعرض W
3. احسب المساحة = الطول × العرض
   S = L × W
4. اطبع المساحة S
5. النهاية

🎯 وظيفة منزلية:

١. اكتب خوارزمية لحساب المتوسط الحسابي لثلاثة أعداد A, B, C

٢. اكتب خوارزمية لحساب مساحة الدائرة

✅ حل الوظيفة:

حل ١ – المتوسط الحسابي:

1. البداية
2. أدخل A, B, C
3. احسب M = (A + B + C) / 3
4. اطبع M
5. النهاية

حل ٢ – مساحة الدائرة:

1. البداية
2. أدخل نصف القطر R
3. احسب S = 3.14 × R × R
4. اطبع S
5. النهاية

🔁 الدرس الثاني: بنى التحكم (حلقات التكرار)

ما حلقات التكرار؟ هي تنفيذ تعليمة برمجية معينة أو عدة تعليمات عدد محدد من المرات.
الفائدة منها: هي اختصار خطوات العمل.

مثال من الواقع: صعود الدرج يتطلب تكرار في الحركة للصعود درجة درجة.

📝 مثال ١: طباعة كلمة "مرحباً" عشر مرات

1. البداية
2. I = 0    (شرط لتكرار الحلقة)
3. طالما I < 10
4.   اطبع "مرحباً"
5.   I = I + 1
6. النهاية

بطريقة أخرى:

1. البداية
2. I = 0
3. هل I < 10 ؟
   نعم:
      اطبع "مرحباً"
      I = I + 1
      أعد الخطوة رقم 3
   لا:
      اذهب إلى النهاية
4. النهاية

📝 مثال ٢: تكرار قراءة عدد حتى إدخال الرقم صفر

1. البداية
2. أدخل عدد X
3. طالما العدد X ≠ 0
4.   اطبع العدد X
5. النهاية

بطريقة أخرى:

1. البداية
2. أدخل عدد X
3. هل العدد X = 0 ؟
   لا:
      اطبع العدد X
      أعد الخطوة رقم 2
   نعم:
      اذهب إلى النهاية
4. النهاية
سؤال مهم: ما الفرق بين الحلقتين في المثالين السابقين؟

الجواب:
  • في المثال الأول: تم تحديد عدد مرات التكرار (10 مرات).
  • في المثال الثاني: لم يتم تحديد عدد مرات التكرار.

📊 جدول المقارنة:

المقارنة تكرار محدد تكرار شرطي
عدد المرات معروف مسبقاً غير معروف
متى يتوقف؟ بعد عدد محدد عند تحقق شرط
مثال كرر 10 مرات كرر حتى X = 0

🎯 وظيفة منزلية:

اكتب خوارزمية تقوم بقراءة عدد ثم تختبره إذا كان هذا العدد أولياً أم لا.

🔀 الدرس الثالث: بنى التحكم (الجمل الشرطية)

تعريف الجمل الشرطية: هي أدوات تستخدم لاتخاذ قرارات مختلفة وتنفيذ مجموعة تعليمات وذلك اعتماداً على شرط معين.

📝 مثال: التحقق من علامة الطالب

اكتب خوارزمية تقوم بقراءة علامة الطالب ثم تختبر العلامة، إذا كانت أكبر أو تساوي 60 اطبع "ناجح" وإلا اطبع "راسب":

تحليل المسألة:

  • المدخلات: علامة الطالب A
  • المعالجة: مقارنة علامة الطالب A >= 60
  • المخرجات: طباعة "ناجح" أو "راسب"

خطوات العمل:

1. البداية
2. أدخل علامة الطالب A
3. إذا A >= 60 عندها
      اطبع "ناجح"
   وإلا
      اطبع "راسب"
4. النهاية

📝 مثال ٢: تحديد إذا كان العدد زوجياً أم فردياً

1. البداية
2. أدخل عدد X
3. إذا كان X/2 = 0 عندها
      اطبع "عدد زوجي"
   وإلا
      اطبع "عدد فردي"
4. النهاية

🎯 وظيفة منزلية:

اكتب خوارزمية تقوم بقراءة عدد ثم تختبره إذا كان هذا العدد أولياً أم لا.

✅ حل الوظيفة (العدد الأولي):

1. البداية
2. أدخل عدد X
3. إذا X <= 1 عندها
      اطبع "ليس أولي"
      اذهب إلى النهاية
4. عيّن I = 2
5. طالما I < X
      إذا باقي قسمة X على I = 0 عندها
         اطبع "ليس أولي"
         اذهب إلى النهاية
      I = I + 1
6. اطبع "أولي"
7. النهاية

المقارنة حلقات التكرار الجمل الشرطية

الاعتماد على عدد أو شرط على شرط معين
مثال كرر 10 مرات إذا A >= 60
