📖 مفهوم حلقات التكرار

ما هي حلقات التكرار؟
هي تنفيذ تعليمة برمجية معينة أو عدة تعليمات عدد محدد من المرات.
الفائدة منها: اختصار خطوات العمل.

مثال من الواقع: صعود الدرج يتطلب تكراراً في الحركة للصعود درجة درجة.

أنواع حلقات التكرار:

النوع عدد المرات متى يتوقف؟ مثال
تكرار محدد معروف مسبقاً بعد عدد محدد كرر 10 مرات
تكرار شرطي غير معروف عند تحقق شرط كرر حتى X = 0
💡 تذكر:
- التكرار المحدد: عدد المرات معروف مسبقاً.
- التكرار الشرطي: عدد المرات غير معروف ويتوقف عند تحقق شرط.

📝 أمثلة عملية

📌 مثال ١: طباعة "مرحباً" عشر مرات

خطوات العمل:

1. البداية
2. I = 0    (عداد الحلقة)
3. طالما I < 10
4.   اطبع "مرحباً"
5.   I = I + 1
6. النهاية

بطريقة أخرى:

1. البداية
2. I = 0
3. هل I < 10 ؟
   نعم:
      اطبع "مرحباً"
      I = I + 1
      أعد الخطوة 3
   لا:
      اذهب إلى النهاية
4. النهاية

📌 مثال ٢: قراءة عدد حتى إدخال الصفر

1. البداية
2. أدخل عدد X
3. طالما العدد X ≠ 0
4.   اطبع العدد X
5. النهاية

بطريقة أخرى:

1. البداية
2. أدخل عدد X
3. هل العدد X = 0 ؟
   لا:
      اطبع العدد X
      أعد الخطوة 2
   نعم:
      اذهب إلى النهاية
4. النهاية
الفرق بين المثالين:
  • المثال ١: عدد المرات معروف (10 مرات) → تكرار محدد.
  • المثال ٢: عدد المرات غير معروف → تكرار شرطي.
