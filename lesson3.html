🔀 الجمل الشرطية

مفهوم الجمل الشرطية – إذا وإلا – أمثلة عملية

📖 مفهوم الجمل الشرطية

تعريف الجمل الشرطية:
هي أدوات تستخدم لاتخاذ قرارات مختلفة وتنفيذ مجموعة تعليمات اعتماداً على شرط معين.

تكوين الجملة الشرطية:

إذا (الشرط) عندها
   نفّذ التعليمات
وإلا
   نفّذ تعليمات بديلة

متى نستخدمها؟

  • عند اتخاذ قرار (ناجح / راسب).
  • عند التمييز بين شيئين (زوجي / فردي).
  • عند التحقق من شرط (أكبر / أصغر).

📊 الفرق بين الجمل الشرطية وحلقات التكرار:

المقارنة حلقات التكرار الجمل الشرطية
الوظيفة تنفيذ تعليمات عدة مرات اتخاذ قرار
الاعتماد على عدد أو شرط على شرط معين
مثال كرر 10 مرات إذا A >= 60

📝 أمثلة عملية

📌 مثال ١: التحقق من علامة الطالب

اكتب خوارزمية تقرأ علامة الطالب، إذا كانت أكبر أو تساوي 60 اطبع "ناجح"، وإلا اطبع "راسب":

تحليل المسألة:

  • المدخلات: علامة الطالب A
  • المعالجة: مقارنة A >= 60
  • المخرجات: "ناجح" أو "راسب"
1. البداية
2. أدخل علامة الطالب A
3. إذا A >= 60 عندها
      اطبع "ناجح"
   وإلا
      اطبع "راسب"
4. النهاية

📌 مثال ٢: زوجي أم فردي

1. البداية
2. أدخل عدد X
3. إذا باقي قسمة X على 2 = 0 عندها
      اطبع "عدد زوجي"
   وإلا
      اطبع "عدد فردي"
4. النهاية

📌 مثال ٣: العدد الأولي

1. البداية
2. أدخل عدد X
3. إذا X <= 1 عندها
      اطبع "ليس أولي"
      اذهب إلى النهاية
4. عيّن I = 2
5. طالما I < X
      إذا باقي قسمة X على I = 0 عندها
         اطبع "ليس أولي"
         اذهب إلى النهاية
      I = I + 1
6. اطبع "أولي"
7. النهاية
