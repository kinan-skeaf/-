📖 مفهوم الخوارزمية

الخوارزمية: هي عدد منتهٍ من الخطوات المتسلسلة لتحقيق هدف محدد في زمن منتهٍ، يمكن التعبير عنها باللغة التي نريد.

🌟 يمكن أن تكون الخوارزمية:

  1. حسابية: تحتوي على عمليات حسابية (مثل جمع أعداد).
  2. غير حسابية: مثل خطوات الاستيقاظ الصباحي والذهاب إلى المدرسة.

✅ خصائص الخوارزمية:

  1. منتهية: عدد خطواتها محدود.
  2. متسلسلة: ذات ترتيب منطقي.
  3. محددة الهدف.
  4. زمن تنفيذها محدد.
  5. قابلة للفهم والتعبير.

🔧 مكونات أي خوارزمية:

المكوّن المعنى
المدخلات (الدخل) المعطيات التي تُجرى عليها العمليات
المعالجة العمليات التي تُجرى على المدخلات
المخرجات (الخرج) النتيجة النهائية
💡 تذكر:
أي خوارزمية = مدخلات + معالجة + مخرجات

📝 أمثلة عملية

📌 مثال ١: جمع عددين

تحليل المسألة:

  • المدخلات: عددان A و B
  • المعالجة: C = A + B
  • المخرجات: C (مجموع العددين)

خطوات العمل:

١. البداية
٢. أدخل قيمة A, B
٣. احسب C = A + B
٤. اطبع C
٥. النهاية

📌 مثال ٢: مساحة مستطيل

تحليل المسألة:

  • المدخلات: الطول L والعرض W
  • المعالجة: S = L × W
  • المخرجات: S (المساحة)

خطوات العمل:

١. البداية
٢. أدخل الطول L والعرض W
٣. احسب S = L × W
٤. اطبع S
٥. النهاية

📌 مثال ٣: متوسط ثلاثة أعداد

تحليل المسألة:

  • المدخلات: ثلاثة أعداد A, B, C
  • المعالجة: M = (A + B + C) / 3
  • المخرجات: M (المتوسط)

خطوات العمل:

١. البداية
٢. أدخل A, B, C
٣. احسب M = (A + B + C) / 3
٤. اطبع M
٥. النهاية
